# SQLAlchemy + Alembic Integration

## 🎯 Что добавлено

### SQLAlchemy ORM
- ✅ **Модели данных** - User, TodoList, Todo, TodoItem, TodoComment, TodoAttachment
- ✅ **Связи между таблицами** - Foreign Keys, Relationships
- ✅ **Валидация данных** - Constraints, Indexes
- ✅ **Методы моделей** - to_dict(), set_password(), check_password()

### Alembic Migrations
- ✅ **Система миграций** - версионирование схемы БД
- ✅ **Автоматические миграции** - autogenerate для изменений моделей
- ✅ **Откат изменений** - downgrade миграций

## 📁 Структура файлов

```
backend/
```

## 🚀 Использование

### Создание таблиц
```bash
# Создать все таблицы
docker compose exec backend python create_tables.py

# Или через db_manager
docker compose exec backend python db_manager.py create
```

### Управление миграциями
```bash
# Создать новую миграцию
docker compose exec backend alembic revision --autogenerate -m "Description"

# Применить миграции
docker compose exec backend alembic upgrade head

# Откатить миграцию
docker compose exec backend alembic downgrade -1

# Показать историю
docker compose exec backend alembic history
```

### Проверка статуса БД
```bash
# Статус таблиц
docker compose exec backend python db_manager.py status

# Debug endpoint
curl http://localhost:5000/debug/db
```

## 🔧 Модели данных

### User
- `id` - Primary Key
- `email` - Unique, Indexed
- `password_hash` - Hashed password
- `created_at` - Timestamp

### TodoList
- `id` - Primary Key
- `user_id` - Foreign Key to User
- `name` - List name
- `color` - Hex color code
- `position` - Sort order
- `created_at` - Timestamp

### Todo
- `id` - Primary Key
- `user_id` - Foreign Key to User
- `list_id` - Foreign Key to TodoList
- `title` - Todo title
- `done` - Boolean status
- `position` - Sort order
- `parent_id` - Self-reference for subtasks
- `created_at` - Timestamp

### TodoItem (Checklist items)
- `id` - Primary Key
- `todo_id` - Foreign Key to Todo
- `title` - Item title
- `done` - Boolean status
- `position` - Sort order
- `created_at` - Timestamp

### TodoComment
- `id` - Primary Key
- `todo_id` - Foreign Key to Todo
- `user_id` - Foreign Key to User
- `content` - Comment text
- `created_at` - Timestamp

### TodoAttachment
- `id` - Primary Key
- `todo_id` - Foreign Key to Todo
- `filename` - Stored filename
- `original_filename` - Original filename
- `file_size` - File size in bytes
- `mime_type` - MIME type
- `file_path` - Storage path
- `created_at` - Timestamp

## 🔄 Миграции

### Создание миграции
1. Измените модели в `models.py`
2. Создайте миграцию: `alembic revision --autogenerate -m "Description"`
3. Проверьте файл миграции в `migrations/versions/`
4. Примените: `alembic upgrade head`

### Пример миграции
```python
def upgrade():
    # ### commands auto generated by Alembic - please adjust! ###
    op.create_table('new_table',
        sa.Column('id', sa.Integer(), nullable=False),
        sa.Column('name', sa.String(length=100), nullable=False),
        sa.PrimaryKeyConstraint('id')
    )
    # ### end Alembic commands ###

def downgrade():
    # ### commands auto generated by Alembic - please adjust! ###
    op.drop_table('new_table')
    # ### end Alembic commands ###
```

## 🎯 Преимущества SQLAlchemy

1. **ORM вместо SQL** - работа с объектами вместо запросов
2. **Автоматические связи** - relationships между моделями
3. **Валидация** - constraints и indexes
4. **Миграции** - версионирование схемы БД
5. **Типизация** - TypeScript-like для Python
6. **Производительность** - connection pooling, lazy loading
